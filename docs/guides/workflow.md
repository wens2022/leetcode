# Workflow Guide | 工作流指南

> How to approach each problem efficiently.

---

## The 3-Stage Protocol | 三阶段方法

### Stage 1 — Solo Attempt | 独立尝试 (20 min max)
- Read the problem carefully
- Write brute force first | 先写暴力解
- No AI, no hints

### Stage 2 — AI as Socratic Tutor | AI辅助

Don't ask for the solution | 不要直接要答案:

```
"I solved it with O(n²). Can you hint at a better approach
without giving the solution?"

"What pattern does this problem belong to?"
```

### Stage 3 — Post-solve Review | 解题后复盘

```
"Explain why this solution is optimal."
"Where else does this pattern appear?"
"What edge cases did I miss?"
```

---

## Weekly Rhythm | 每周节奏

```
Monday    → New problem (45 min)
Wednesday → New problem (45 min)
Friday    → New problem (45 min)
Sunday    → Review one past problem, explain in English
```

Total: ~3 hours/week | 每周约3小时.
